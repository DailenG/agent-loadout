## Spec ambiguities resolved

1. **First run.** The migration wizard is M20; the "Add a backup remote" step is a dialog the shell shows while there is no remote and this machine has not answered it (`state/local-settings.toml`). M20 can host the same component.
2. **Remote status without network.** `behind` for a git remote is from the last fetch (pull); for a folder remote it counts sibling machines' commits. "In sync" means ahead 0 and behind 0.
3. **Restore of a version** commits without applying and opens the apply drawer (SPEC 9.5); "Restore entity..." is the same with picked entities.
4. **Download zip** is the store at that version plus `EXPORT.json`, the format `restore --from` reads.

## Deviations

- Conflicts of a pull are listed on the History page but not resolved there (the merge resolver of SPEC 9.9 step 5 is not in this milestone); the page points to the CLI.
- `on-commit` and interval pushes/pulls (SPEC 9.8) are not scheduled by the app; Push and Pull are buttons.
- Not offered: Device flow (no core support yet), "Create private repository" (CLI `remote create-github` only), restore from a zip file in the GUI (CLI only), configurable auto-tag retention (fixed 90 days, shown read-only).
- Pill toasts for `confirmation_required` on an older undo show an error notice next to the confirm dialog (same as the M15 drawer).
- `tokens.css` additions of the Settings slice were appended with a shell heredoc rather than the edit tool.
