# M48 Git-missing catalog notice (0.7.0, #29)

Status: implemented. Not committed (the maintainer commits).

## What was built

- **Core message** (`crates/agent-loadout-core/src/remote/git.rs#git_not_found`): one sentence for a missing git,
  "Git isn't installed or isn't on PATH; install Git to use <what>." (`tool_not_found`). Used by `GitCli::from_env`
  ("Git remotes") and `skills::install::git_path` ("Git skill sources, MCP servers from Git, and Git catalogs"),
  which also serves Git taps and MCP servers from Git. The old texts ("git is not installed or not on PATH; git
  ... need it") are gone.
- **No repeated wording in the app**: `failureSentence` (`src/i18n/en.ts`) shows a `tool_not_found` error's own
  message instead of the generic "A required program is not installed or not on PATH."; other codes are unchanged.
  Used by `catalogText.ts#ipcErrorText` (which used to print "<generic> (<detail>)"), `skills/labels.ts#failureText`
  (skills from Git, Browse toasts) and `McpSourcePanel.tsx` (MCP from Git).
- **Install > Browse**: a Git catalog whose search fails with `tool_not_found` shows a neutral status line (no
  `role="alert"`, `catalog-status--neutral`), "Git isn't installed, so Git catalogs can't be searched. Install Git
  to use them.", a **How to fix this** button and **Try again**. Offline still wins, as for other errors.
- **IPC**: `open_help(topic)` opens a troubleshooting entry from a fixed table (`tools.rs#HELP_PAGES`; only
  `git_missing`); any other topic is `invalid_value`, so no caller URL is ever opened. Bindings regenerated.
- **Docs**: `docs/troubleshooting.md` "Git isn't installed, so Git catalogs can't be searched".

## Tests

- `crates/agent-loadout-core/tests/remote_git.rs#missing_git_is_one_clear_sentence`: exact sentences, PATH named
  once, no generic text.
- `src-tauri/src/commands/tests.rs#help_pages_come_from_the_fixed_table`: the URL's anchor matches the docs heading;
  other topics are refused.
- `BrowsePanel.test.tsx` "says plainly that Git is missing ...": wording, neutral class, no alert, no repeated
  text, Try again present, the link calls `openHelp("git_missing")`.
