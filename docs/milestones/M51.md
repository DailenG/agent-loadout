# M51 Optional external scanner: SkillSpector in the app (0.8.0, #30)

Status: **done** (0.8.0). Written against the M50 contract; the app commands and `src/ipc/bindings.ts` match it.

## What was built

- **Settings > Security** (`src/app/routes/settings/security/SecuritySection.tsx`): the SkillSpector section with the
  exact disclosure (the M50 `DISCLOSURE` sentences) and a link to the project at v2.13.7 (`open_help("skillspector")`);
  Status (Ready through uvx or on PATH with its version, the untested-version note, Needs Prepare, Not available,
  "on but can't run here", Check again); setup instructions when nothing is found (uv link via
  `open_help("uv_install")`, `pipx install skillspector==2.13.7 --python 3.13`, Python 3.14 not supported); Prepare
  with an indeterminate progress bar whose `aria-valuetext` and live region carry uv's last line, one button that
  switches between Prepare and Cancel Prepare (focus stays on it; after success focus moves to the Status badge), a
  Cancel that wins even before Prepare reaches the backend, progress that survives leaving Settings, and uv's last
  line kept after a failure; the time limit (display; `timeout_secs` in the file); the "Use SkillSpector" switch
  (disabled until ready, can always be turned off, also during Prepare); a line for a 0.7.0 Snyk leftover.
- **External scan in reviews** (`src/app/components/ExternalScan.tsx`, install and update reviews): runs whenever the
  scanner is on and ready (local folders too); "Not scanned (<reason>)" without running anything when on but not
  ready; findings with severity, rule id, `file:line`, message and excerpt; "Not fully scanned" never reads Clean;
  Install anyway / Update anyway only after the box, which is cleared with each new result; Cancel scan and Scan
  again with focus kept; a failed Scan again clears the previous result, and Install / Update wait for a finished
  scan (the backend refuses them without a report).
- **Library**: "Scan with SkillSpector" on a library skill when on and ready, with a report dialog.
- **Mock** (`src/test/scannerData.ts`): every state, matching the backend's Prepare order (locked, canceled,
  unavailable), pending cancel and switch-off; `?scanner=on|off|prepare|none|path|incomplete|garbled|failed|timeout|slow`
  for `npm run dev:mock`.

## Tests

`ExternalScan.test.tsx` and `SecuritySection.test.tsx`: nothing runs or shows while off; not ready never calls a
scan and never gates; dangerous and DO_NOT_INSTALL gate; incomplete never looks clean; not scanned, failed and not
understood never block and never read Clean; Install anyway tied to the result shown; cancel and Scan again; update
review gating and the failed Scan again; library action; disclosure text exact; setup; Prepare progress, cancel,
pending cancel, failure, focus, surviving navigation; switch off during Prepare; Snyk leftover.
